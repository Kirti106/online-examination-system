# Project Statement

## Project Title

Online Examination & Automated Evaluation System

## Problem Statement

Traditional examination processes often require manual question management, answer evaluation, result calculation, and record maintenance.

The Online Examination & Automated Evaluation System provides a web-based solution for conducting objective examinations. It allows students to attempt examinations online while automatically evaluating their answers and generating results.

The system also provides administrators with facilities to manage examinations, questions, and student examination records.

## Scope of the Project

The project covers the development of a Java-based web application for conducting and managing online MCQ examinations.

The scope includes:

- Student registration and authentication
- Administrator authentication
- Examination management
- Question management
- Online examination with a timer
- Answer submission
- Automatic evaluation
- Result generation
- Student result history
- Student record viewing by administrators
- Persistent storage using MySQL
- Role-based access control

The project is focused on objective/MCQ-based examinations.

## Target Users

### 1. Students

Students can:

- Register in the system
- Log in securely
- View available examinations
- Attempt examinations
- Submit answers
- View automatically generated results
- View previous examination results

### 2. Administrators

Administrators can:

- Log in to the system
- Create and manage examinations
- Add and manage examination questions
- View registered students
- View examination results

## High-Level Features

- User registration and login
- Role-based student and administrator access
- Examination CRUD operations
- Question CRUD operations
- MCQ examination interface
- Examination timer
- Answer storage
- Automatic evaluation
- Score, percentage and grade calculation
- Student result history
- Administrator result dashboard
- MySQL database integration
- Exception handling
- Java multithreading
- Git-based version control
